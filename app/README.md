# DriveStream app (Android phone + Android TV)

One React Native / Expo codebase for both. It talks to your DriveStream server: the address you
build in with `DRIVESTREAM_SERVER` (see `.env.example` and `app.config.js`), changeable on the sign-in screen.

- Sign in with your DriveStream profile, or with a code/QR approved from another device; the session is kept in secure storage.
- Home with Continue Watching (long-press a card to remove it), Recently Added, categories and genres.
- Title pages with seasons and episodes, category browsing and search.
- Native player (ExoPlayer): plays MKV, HEVC, AC3 and more directly. Quality menu (original files
  plus converted lower resolutions), subtitles from `.srt`/`.vtt` files, resume, Skip Intro, and
  Next Episode when the credits start.
- TV: everything works with the remote. In the player, with the controls hidden, ◀/▶ seek 10 s and OK pauses.

Building: see the main README → "Android phone and Android TV app".

## Develop

`src/app/` holds the screens (Expo Router), `src/components/` the shared UI, `src/lib/` the API client.

```bash
npx tsc --noEmit                              # typecheck
npx expo export --platform android            # check the bundle builds
```

`android/` is generated by `npx expo prebuild`; configure native behaviour in `app.json`, `app.config.js` and `plugins/`.
